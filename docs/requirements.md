# 要件定義書 — 検体検査装置 操作画面（試作）

| 項目 | 内容 |
|---|---|
| 版 | 1.0（2026-11-11） |
| 対象 | `lvgl-demo`（PC シミュレータ上の試作） |

## 1. 目的

検体検査装置の操作画面を LVGL 8.3.11 で試作し、次の 2 点を確認する。

1. LVGL 8.3.11 で、装置の操作画面に必要な表示・操作が実現できること
2. 実機（組込み Linux）が無い段階でも、PC 上で GUI の開発とテストを進められる構成にできること

## 2. 前提・制約

| ID | 内容 |
|---|---|
| C-01 | 表示は 800×480 のタッチパネルを想定する（PC ではウィンドウとマウスで代用） |
| C-02 | GUI ライブラリは LVGL 8.3.11 に固定する（v9 は API が異なるため使わない） |
| C-03 | 実装言語は C++20（LVGL 本体は C） |
| C-04 | 装置ハードウェアは模擬実装とする。測定値・温度は乱数で生成する |
| C-05 | 実機への移植時に、表示・入力・装置制御の実装を差し替えるだけで済む構成にする |

## 3. 用語

| 用語 | 意味 |
|---|---|
| 検体 | 測定対象の試料 1 本。ラック上の位置・検体ID・検査項目を持つ |
| 基準範囲 | 検査項目ごとの正常とみなす値の範囲。外れた結果に H（高値）/ L（低値）を付ける |
| 要再検 | 測定に失敗し、測り直しが必要な状態 |
| 反応セル | 試料と試薬を反応させる部分。一定温度（37.0 ℃）に保つ必要がある |

## 4. 機能要件

| ID | 要件 |
|---|---|
| FR-01 | ラック上の 10 検体を一覧表示する（位置・検体ID・項目・状態・結果） |
| FR-02 | 「開始」で、待ち状態の検体を位置の若い順に 1 本ずつ測定する（1 本 3 秒） |
| FR-03 | 「停止」で一時停止する。測定中だった検体は中断して「待ち」に戻し、再開時に測り直す。一時停止中は経過時間を進めない |
| FR-04 | 一時停止中は「再開」で続きから測定する |
| FR-05 | 「リセット」で全検体を「待ち」に戻し、結果を消す。測定中は受け付けない |
| FR-06 | 結果が基準範囲外なら H / L を付け、注意色で表示する。基準範囲の境界値は範囲内とする |
| FR-07 | 測定に失敗した検体は「エラー」とし、結果欄に「要再検」と表示する |
| FR-08 | 測定中の検体・その進み具合（%）・処理済み件数・経過時間を表示する |
| FR-09 | 反応セル温度を 0.5 秒ごとに表示し、推移をグラフで示す。37.0±0.2 ℃ を外れたら注意色にする。温度監視は待機中も行う |
| FR-10 | 全検体の処理が終わったら、件数・基準範囲外の件数・エラー件数をダイアログで知らせる |
| FR-11 | ボタンは状態に応じて有効・無効を切り替える（下表） |

FR-11 のボタン状態:

| 装置の状態 | 開始 | 停止 | リセット |
|---|---|---|---|
| 待機中 | 有効（開始） | 無効 | 無効 |
| 測定中 | 無効 | 有効 | 無効 |
| 一時停止 | 有効（再開） | 無効 | 有効 |
| 測定完了 | 無効 | 無効 | 有効 |

## 5. 非機能要件

| ID | 要件 |
|---|---|
| NFR-01 | 応答性: 装置制御は GUI とは別のスレッドで行い、ボタン操作は即座に戻る（GUI が止まらない） |
| NFR-02 | スレッド安全性: LVGL の API は GUI スレッドからだけ呼ぶ。スレッド間で共有するデータはロックで守るか、コピーして渡す |
| NFR-03 | 移植性: 表示先・入力元・装置ハードウェアをインターフェースで分け、実機への移植でそれ以外を変更しない |
| NFR-04 | テスト容易性: 検査の進行ロジックと表示文言の生成は、LVGL・ウィンドウ無しで単体テストできる |
| NFR-05 | 画面の検証: 決まった操作手順での画面を自動で再生・照合でき、意図しない見た目の変化を検出できる |
| NFR-06 | 日本語表示: 画面で使う字だけをフォントに収録する。フォントに無い字の表示を自動テストで検出する |
| NFR-07 | メモリ: 描画バッファは画面全体ではなく 40 ライン分とする（部分描画） |
| NFR-08 | 配布: 実行ファイル単体で動作する（ランタイムの別途インストールを不要にする） |

## 6. 対象外

実機ハードウェアの制御、LIS（検査情報システム）との通信、利用者認証・操作ログ、多言語切り替え、
試薬・消耗品の管理、精度管理（QC）。
